# Consumo de API en Angular

Aplicación desarrollada en Angular que consume una API REST pública y muestra los datos en una tabla.

## Tecnologías
- Angular
- TypeScript
- HTML / CSS
- API: https://jsonplaceholder.typicode.com/

## Funcionalidades
- Consumo de API con HttpClient
- Uso de servicios
- Visualización de datos en tabla
- Manejo de errores

## Ejecución
```bash
npm install
ng serve
